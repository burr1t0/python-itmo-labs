# Лаб 4. Telegram-бот

Telegram-бот с интеграцией погодного API. Две реализации: синхронная и асинхронная.

## Файлы

- `async_bot.py` — асинхронная версия на aiogram
- `sync_bot.py` — синхронная версия на python-telegram-bot
- `constants.py` — токены и константы

## Функциональность

- Получение текущей погоды по городу через внешний API
- Парсинг и форматирование данных

## Технологии

Python 3, aiogram, python-telegram-bot, REST API
