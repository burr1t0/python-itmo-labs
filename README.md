# Python Labs — ИТМО, Инженерия ИИ

Лабораторные работы по Python, 1 курс, факультет инженерии ИИ, ИТМО.

## Состав

- **lab1** — Шифрование (Цезарь, Виженер, RSA, взлом)
- **lab2** — Сапёр (консольная игра)
- **lab3** — PyGit (собственная реализация системы контроля версий)
- **lab4** — Telegram-бот (парсинг данных, погодный API)

## Технологии

Python 3, aiogram, REST API
