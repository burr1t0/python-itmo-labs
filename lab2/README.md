# Лаб 2. Сапёр

Консольная реализация игры «Сапёр» с движком и автоматическим решателем.

## Файлы

- `minesweeper_engine.py` — игровой движок (логика поля, мины, открытие клеток)
- `play_minesweeper.py` — консольный интерфейс для игры
- `solver.py` — автоматический решатель

## Технологии

Python 3
